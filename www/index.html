와일드카드

#이름 을 한 줄에 홀로 쓰면 풀 정의, 프롬프트 안에 쓰면 그 풀에서 하나를 뽑습니다. 슬롯마다 따로 뽑습니다 — 한 배치 안에서도 장마다 다른 조합이 나옵니다. {a|b} 와 ||a|b|| 도 씁니다.

인핸스

원격 작업

처음이면 — 지시함 저장소 만들기
  1. 새 저장소를 만듭니다. 이름은 아무거나, 공개 여부는 Private 을 권합니다 — 프롬프트가 그대로 남는 곳입니다.
  2. AI 에게 세팅을 시킵니다. 아래 문구를 복사해 Claude Code·Codex 에 그대로 붙여넣으면 규약 파일(AGENTS.md · CLAUDE.md)과 폴더를 만들어 줍니다.
  3. 비공개로 만들었다면 읽기 전용 토큰을 위 칸에 넣습니다 (Settings → Developer settings → Fine-grained tokens → 그 저장소에 Contents: Read).
  4. 위 저장소 칸에 내이름/저장소이름 을 적고 저장하고 확인.

폴더는 이렇게 갑니다 — 작품마다 하나씩, 그 안에 인물과 슬롯:

미아/
  characters/미아.json     ← 인물 (그 작품 안에서 공용)
  slots/일상.json          ← 슬롯 묶음 = 작업 하나
  slots/H.json
리사/
  characters/리사.json
  slots/교복.json

★슬롯 파일이 새로 생기거나 내용이 바뀌면 그것이 새 작업이 됩니다. 인물 파일을 고치는 것은 작업을 만들지 않습니다 — 다음에 그 작품을 돌릴 때 최신 인물을 씁니다.

꺼 두면 목록만 받아 오고, 실행은 아래에서 눌러 정합니다. ★켜 두면 물어보지 않고 Anlas 를 씁니다.

지시 파일 모양

슬롯 파일 — 미아/slots/일상.json

{
  "name": "미아 · 일상",
  "prefix": "1girl, silver hair, masterpiece",
  "slots": [
    { "name": "1-1", "content": "smile, bedroom" },
    { "name": "1-2", "content": "angry, classroom" }
  ],
  "options": { "count_per_slot": 1 }
}

인물 파일 — 미아/characters/미아.json

{ "name": "미아", "content": "1girl, silver hair, blue eyes" }

저장 폴더는 작품 폴더 이름을 씁니다. 슬롯 파일에 folder 를 적으면 그것이 이깁니다. options 는 아는 값만 받습니다 — 모델·크기·steps·cfg· 샘플러·UC·퀄리티·네거티브·배수·한 명 모드·투명 배경·저장 형식·Variety+·시드.

PC 에서 올리는 법

수신함이 떠 있는 PC·VPS 에서:

python tools/job.py --url 192.168.0.5:8770 --token 토큰 \
       push --file 작업.json

작업 JSON 은 PeroFix 가져오기와 같은 모양입니다 (prefix · slots · characters). options 로 배수·투명 배경 같은 것도 함께 정할 수 있습니다.

세부 설정

작가 태그

★미리보기 그림은 Danbooru 에서 그대로 옵니다. 수위는 여기서 정합니다.

반영율이란

★정직하게 말하면 추정입니다. NAI 가 무엇을 얼마나 배웠는지는 공개되지 않았습니다. 다만 학습이 Danbooru 를 바탕으로 한 이상 그림 수가 곧 학습량이고, 그림이 적은 작가는 실제로 잘 안 나옵니다. 그래서 장수를 그대로 눈금으로 쓰되 「몇 장이라 이 등급인지」를 같이 적어 직접 판단하실 수 있게 했습니다.

★장수가 많아도 최근에 몰려 있으면 학습 시점 이후라 안 먹을 수 있습니다. 그래서 「몇 %가 몇 년 이전인지」도 함께 적습니다.

섞기

위에서 작가를 눌러 담으면 여기서 섞습니다.

★끄면 절대값이 됩니다. 다섯 명한테 전부 1.2 를 주면 프롬프트가 작가 쪽으로 쏠려 구도·표정·의상 태그가 밀려납니다. 켜 두면 한 명을 올릴 때 나머지가 조금씩 내려가서, 「이 작가를 더 세게」가 다른 것을 망가뜨리지 않습니다.

세기는 숫자::태그:: 로 적힙니다. 1.0 인 작가는 문법을 안 붙입니다 — 뜻은 같은데 프롬프트만 지저분해지기 때문입니다.

작가 태그를 잔뜩 넣고 뽑았는데 그림의 어떤 요소가 누구 때문인지 모를 때 씁니다. 20개를 하나씩 빼 보면 20장이 들지만, 절반씩 빼며 좁히면 5라운드면 끝납니다.

장수가 두 배로 늘지만, 한 명이 만든 것이 아닌 경우를 알아낼 수 있습니다. 왼쪽을 빼도 남고 오른쪽을 빼도 남으면 그 요소는 여럿이 함께 만든 것입니다.

세기 맞추기

범인을 찾았으니 이제 얼마나를 정합니다. 한 명만 1차원으로 훑으므로 가짓수가 곱해지지 않습니다.

왜 절반씩 빼는가

★넣기가 아니라 빼기여야 합니다. 절반만 넣고 뽑으면 그림이 통째로 달라져 무엇 때문에 달라졌는지 알 수 없습니다. 전체를 유지한 채 절반을 빼야 나머지 화풍이 남은 상태에서 그 요소만 사라졌는지 보입니다.

★누구인지와 얼마나를 절대 같이 돌리지 않습니다. on/off 20개는 220, 거기에 세기 5단계를 곱하면 520 이라 훑을 수 없습니다. 범인을 먼저 on/off 로만 찾고(세기는 전부 1.0 으로 묶습니다), 세기는 그 뒤에 한 명만 훑습니다. 합쳐서 10장 안팎이면 끝납니다.
